Unlike Marksheet/ Admit Card Structure, this is NOT per-class — a TC's content is the same regardless of which class the leaving student was in, so there is exactly one school-wide structure, not a per-class list. Fields split into a locked always-on group (what every TC legally needs - Name, Father's Name, DOB, Class Left From, Date of Leaving, Reason) and an optional group a school can toggle (Conduct Remark, Subjects Studied, Attendance %, Fee Dues Cleared, Games/Extra-Curricular).
