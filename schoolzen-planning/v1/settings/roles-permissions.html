Reference file - this is the exact, approved render. Match it pixel-for-pixel. Settings → Roles & Permissions. Implements R3's permission system as an actual UI: a role tab strip + a module×action matrix of checkboxes. "Class Teacher" is scoped (its checkbox row shows a clickable "Scoped" tag opening a small picker for WHICH class+section this grant applies to) rather than a blanket module permission, matching R3's specific "Class Teacher = permission scoped to a Class+Section, not the whole school" rule. Admin/Super Admin are locked, uneditable roles (the school always needs at least one role with full access that can't be misconfigured into a lockout).
